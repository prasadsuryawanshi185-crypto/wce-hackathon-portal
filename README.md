## ⚡ Overview

WCE Hackathon is India's premier student-run 24-hour engineering crucible. Designed with dual calibrated tracks, real-time code audit checkpoints, and ₹1,00,000+ in bounties, the hackathon brings together 500+ top engineering innovators across the country to solve real-world problems.

- **Official Website Reference**: [wcehackathon.in](https://www.wcehackathon.in/)
- **Registration Platform**: Powered by [Unstop](https://unstop.com)

- **Host Campus**: Walchand College of Engineering, A/P Vishrambag, Sangli, Maharashtra 416415

## 🎯 Dual Calibrated Tracks

1. **Novice Track (1st & 2nd Year Undergraduates)**:
   - Smart Campus & Connected IoT
   - Digital FinTech & Financial Literacy
   - Interactive EdTech & Simulation
   - Health, Wellness & Assistive Tech
   - Civic & Community Impact
   - Environmental Sustainability & CleanTech

2. **Expert Track (3rd & 4th Year+ Developers)**:
   - **GraphMind**: User-Centric Long-Term Memory (Hybrid Graph + Vector search isolation)
   - **Minimal Dataset Versioning System**: Content-addressable Merkle tree ML versioning
   - **Grounded RAG with Verified Citations**: Zero-hallucination provenance pipeline

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Cyberpunk / Exhibition Glassmorphism Theme
- **3D & Graphics**: Three.js + @react-three/fiber + @react-three/drei
- **Animations**: Framer Motion
- **Icons**: Lucide React
